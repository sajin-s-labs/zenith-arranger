## ⚡ The Vision

Flagship arranger keyboards (such as the Yamaha PSR-SX920 / Genos or Korg Pa5X) cost thousands of dollars. Millions of hobbyists, church keyboardists, and gigging musicians play entry-to-mid-range digital keyboards (such as the **Yamaha PSR-E463**, Casio CT-X, or Roland E-X). While these keyboards have great keybeds and powerful built-in stereo speakers, their built-in rhythm styles are rigid, limited in variety, and cannot be expanded with modern studio-grade loops.

**Zenith Arranger** transforms an Android phone or tablet resting on your keyboard's music stand into the "brain upgrade" for your instrument. Connected via a single USB cable and an auxiliary audio cable, it acts as an ultra-responsive, zero-latency workstation engine that synchronizes directly with your keyboard's keys and transport.

## 🔌 Hardware Setup & Signal Routing

The physical setup is mobile, self-contained, and requires zero external audio interfaces:

```
┌────────────────────────────────────────────────────────┐
│                   Yamaha PSR-E463                      │
│                                                        │
│  [Keybed / USB TO HOST]        [AUX IN / Stereo Spkrs] │
└───────────┬────────────────────────────────▲───────────┘
            │                                │
  USB-B to USB-C (MIDI)          3.5mm TRRS to 3.5mm Aux
  [Sends Note/Clock/Triggers]    [Audio back into keyboard]
            │                                │
            ▼                                │
┌────────────────────────────────────────────┴───────────┐
│              Android Phone (Zenith Arranger)           │
│                                                        │
│  • Jetpack Compose Workstation UI                      │
│  • C++ Oboe Audio Engine (Isolated Real-Time Thread)   │
└────────────────────────────────────────────────────────┘
```

1. **USB MIDI Input**: Connect USB-B on the keyboard to USB-C on the phone. Zenith Arranger automatically detects the keyboard, captures key presses, and synchronizes to incoming MIDI clock.
2. **Aux Audio Output**: Connect the phone's 3.5mm headphone jack directly into the keyboard's **AUX IN**. The rhythm styles and accompaniment play directly through the keyboard’s internal high-power stereo speakers.

## 🛠️ Building & Installation

### Prerequisites
* **Android Studio Ladybug / Meerkat** (or CLI toolchain)
* **JDK 17** (OpenJDK 17 / Temurin)
* **Android SDK**: API 35 (compileSdk 35, minSdk 26)
* **Android NDK**: `28.2.13676358` (NDK r28)
* **CMake**: `3.22.1+`

### 1. Clone the Repository
```bash
git clone https://github.com/sajin-s-labs/zenith-arranger.git
cd zenith-arranger
```

### 2. Build Debug APK
```bash
./gradlew assembleDebug
```
The compiled APK will be at `app/build/outputs/apk/debug/app-debug.apk`.

### 3. Build Release APK
```bash
./gradlew assembleRelease
```
The release APK will be generated at `app/build/outputs/apk/release/app-release.apk`.

### 4. Direct Device Sideload via Script
If your Android device is connected via USB debugging:
```bash
chmod +x deploy.sh
./deploy.sh
```
